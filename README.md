# CS2 Vault

Premium dark-and-gold public showcase for Steam CS2 inventory.

- Steam profile: https://steamcommunity.com/profiles/76561199781756585
- Inventory API: Steam Community Inventory (730/2)
- Currency display: VND-ready; live item valuation is not enabled until a trusted pricing source is configured.
- No Steam password, Steam Guard code, or session cookie is required.

Deploy on Render with `npm install` and `npm start`. Set `STEAM_ID=76561199781756585`.
Steam profile, Game Details, and Inventory privacy must be Public.
